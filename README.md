# ANUSHIL HOME TUITION — PRO VERSION

Included in this package:
- Student-facing responsive app
- Course catalogue
- Study material section
- Online demo quiz with automatic scoring
- Student profile
- Schedule
- Notices stored locally
- Contact/call/email
- Admin-demo area
- Production database SQL blueprint for students, courses, materials, tests, results, notices, payments and attendance

## Important
The app UI is ready, but real cloud login, database, PDF/video uploads, online payments and push notifications require deployment credentials and external service configuration. No fake credentials or payment gateway keys are included.

## Quick run
Open `index.html` in a browser. For a real Android APK, package the web app with a wrapper such as Capacitor after hosting the frontend/backend.
